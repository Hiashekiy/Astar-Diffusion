## 0. 本阶段回答什么

> Diffusion 轨迹引导场能否为图搜索提供**目标距离之外**的有效空间先验？与目标距离结合后，能否在保持可行性的同时减少无效扩展？

只改**搜索优先级**，不改引导场、不改轨迹、不改碰撞检测。固定：M0 源点（删除障碍内采样点，保留原 `u`）、四邻域、单位边代价、Manhattan 距离、λ 沿用 Stage 2A。

## 1. 六种优先级

| 编号 | 方法 | J(n) | 用场 |
|---|---|---|---|
| B0 | A\* 基线 | `g + h` | 否 |
| B1 | Distance-GBFS | `d̂_G` | 否 |
| B2 | Field-Only | `−F̂` | 是 |
| B3 | Linear Fusion | `α·d̂_G − (1−α)·F̂` | 是 |
| B4 | Nonlinear Fusion | `α·d̂_G^γ − (1−α)·F̂`（γ=0.5） | 是 |
| B5 | Adaptive Fusion | `α(n)·d̂_G^γ − (1−α(n))·F̂`，α: 0.25→0.75 | 是 |

归一化：`F̂ = (clip(F, −0.1, 1.0) + 0.1)/1.1`（**直接读 Stage 2A 的 `FIELD_CLIP`**，不另写常数）；`d̂_G = d_G / D_max`，`D_max` 为当地图自由格最大 Manhattan 距离。

B1–B5 的优先级函数**物理上拿不到 `g`**（只接收预先算好的 `F̂`、`d̂_G` 标量图），这是验收项 4 的检验对象，而不是靠自律。

## 3. 最重要的发现：引导场的价值取决于输入轨迹的质量

按轨迹等级分组（linear 场）：

| 等级 | B0 A\* | B1 距离 | B2 Field-Only | B3 (α 均值) |
|---|---|---|---|---|
| G0 feasible | 1542 / 1.000 | 488 / 1.141 | **137 / 1.000** | 246 / 1.014 |
| G1 mild | 1542 / 1.000 | 488 / 1.141 | **205 / 1.004** | 285 / 1.020 |
| G2 moderate | 1542 / 1.000 | 488 / 1.141 | 459 / 1.055 | 415 / 1.080 |
| G3 severe | 1542 / 1.000 | 488 / 1.141 | 544 / 1.066 | 526 / 1.097 |

- **G0/G1（轨迹基本无碰撞）**：Field-Only 只用 137/205 次扩展就到终点，**比纯距离贪心还少 58–72%**，且 G0 下路径恰好等于最短路径（L/L\*=1.000）——此时引导场是比目标距离强得多的先验。
- **G2/G3（轨迹穿墙严重）**：Field-Only 退化到 459/544 次，**比纯距离贪心（488）更差**；融合目标距离后（B3）回到 415–526，代价是路径变长 8–10%。

这条曲线直接对应假设 H1/H2：**先验有用，但用多少取决于输入有多可信**。这也解释了为什么方案要求把 G0–G3 分开统计。

## 4. 参数效应

**α（距离项权重，B3/B4 linear）：**

| α | B3 expanded/A\* | B3 L/L\* | B4 expanded/A\* | B4 L/L\* |
|---|---|---|---|---|
| 0.25 | 0.204 | 1.042 | 0.205 | 1.041 |
| 0.50 | 0.222 | 1.045 | 0.206 | 1.044 |
| 0.75 | 0.272 | 1.072 | 0.258 | 1.062 |

α 增大 → 扩展数增加、路径变差，逐步向 Distance-GBFS（0.311 / 1.141）靠拢，**风险 R2 得到确认**。本数据集上小 α 更好，但这与 §3 一致：轨迹质量越好，越该信场。

**γ=0.5 vs γ=1.0：** γ=1.0 在数学上等于 B3，代码里也逐位复现（单测 `test_gamma_one_reproduces_linear_fusion` 断言 expanded 与 path 完全相同），所以主实验只跑 γ=0.5。B4 相对 B3 在 α≥0.5 时略优（0.206 vs 0.222，0.258 vs 0.272），α=0.25 时无差别 —— **H3 只得到微弱支持**。

**quadratic vs linear 场：** quadratic 在每个方法上扩展数都更多（+4%…+17%），路径略差，与 Stage 2A 的观察一致（quadratic 把源点影响力集中到终点侧，损失了空间结构）。

## 5. 风险 R5：先被证实，后被消掉

第一版场构建（Stage 1 的 heapq 实现）平均 **6.57 ms**，而搜索只要 0.55 ms，端到端
`7.1 ms vs A* 4.0 ms`——慢 1.8×，"节点少 5 倍"完全被场构建吃掉。

按 `docs/propagation-benchmark.md` 的优化（NumPy 同步传播 + 去掉多余连通域 BFS + 预计算邻居表）后：

| | Search ms | Field build ms | **Total ms** |
|---|---:|---:|---:|
| A\* | 4.014 | — | **4.014** |
| B2 Field-Only linear | 0.532 | 2.281 | **2.813** |
| B4 Nonlinear linear | 0.567 | 2.282 | **2.849** |
| B3 Linear linear | 0.604 | 2.281 | **2.885** |
| B5 Adaptive linear | 0.612 | 2.282 | **2.894** |
| B3 Linear quadratic | 0.646 | 2.358 | **3.004** |

场构建 6.57 → **2.32 ms（2.8×）**，端到端因此**反超 A\*（2.89 vs 4.01 ms，快 1.39×）**，
同时仍只用 A\* 的 1/5 扩展、路径长 4%。R5 成立的前提——"场必须摊销"——现在只需要一次
2.3 ms 的构建，不再是数量级障碍。

## 7. 结论与后续

1. **引导场确实提供了目标距离之外的空间先验**：G0/G1 下扩展数比纯距离贪心少 58–72%，且路径质量显著更好（1.000 vs 1.141）。
2. **融合是必要的保险**：轨迹变差时 Field-Only 会劣于纯距离贪心，加入 α=0.25–0.5 的距离项可拉回，代价是 4–8% 的路径长度。
3. **推荐配置**：B3 linear α=0.25（0.204× A\* 扩展，1.042× 长度）或 B2 linear（1.031× 长度、0.218× 扩展），quadratic 场不建议用于搜索。
4. **不要声称最短路径最优**：B1–B5 平均 L/L\*=1.056，仅 50.8% 的样例恰好等于 L\*。
5. **端到端已经赢了，但前提是场构建要快**：优化后 2.89 ms vs A\* 4.01 ms。若地图更大或需要多次查询，应把场缓存起来（`docs/propagation-benchmark.md` 给出了按地图指纹实测择优的做法）。
